# 内部产品编码与三端权限规则

状态：2026-10-29 用户确认的目标规则；具体代码及真实环境验收以实施报告为准。

| 段位 | 取值 | 含义 |
|---|---|---|
| 固定前缀 | `ZJ` | 中技拼音首字母 |
| 系列 | `D`、`Y`、`S`、`A` | 密鼎、密翼、密塾、AI+ |
| 产品类型 | `S`、`H` | 软件、软硬件 |
| 产品属性 | `A`、`B` | 自研、合作 |
| 流水号 | `001` 至 `999` | 同一系列、类型、属性组合内分配；用尽后拒绝分配并提示管理员 |

例如 `ZJ-D-S-A-001` 表示密鼎系列的软件、自研产品，在该组合中的第一个编号。管理员选择系列、产品类型和产品属性，系统生成编号；编号生成后保持不变。产品类型由管理员选择，不从内容模板自动推断。内部编码仅供内部使用；对外展示产品型号，产品型号与内部编码一一对应。

型号去除首尾空白并按 Unicode 兼容形式及大小写规范化后检查唯一性。型号修改后，旧型号继续保留给同一产品，避免与仍在线的历史发布快照发生冲突。正式环境启用前应核验并建立所有存量型号与编码的索引；本地事务替身结果不能代替真实云并发验收。

现有 27 款产品的型号及自研/合作属性暂可留空；属性未核实前保留原编码，后续在输入核实、旧新映射与引用检查完成并获得真实环境操作授权后迁移。预检工具只输出建议和缺口，不会连接云环境或修改数据。内部编码规则的公司正式公告由业务人员负责。

| 功能 | 管理 PC | 销售 PC | 小程序 / H5 |
|---|---|---|---|
| 身份 | 管理员或内容管理员 | 经授权的销售人员 | 访客 |
| 维护产品及资料 | 按角色授权 | 不可 | 不可 |
| 宣传资料 | 管理所有版本 | 已发布的当前版本 | 已发布的当前版本 |
| 技术资料 | 管理所有版本 | 已发布的当前版本 | 不可见 |
| 下载资料 | 管理员按权限管理 | 按权限下载当前版本 | 不提供原件下载入口 |
| 管理站点配置、记录及反馈 | 按角色授权 | 不可 | 可按功能提交反馈 |

分类不明的旧资料不对外。资料从宣传改为技术时保存后收紧对外访问；改回宣传需重新发布。已经到达设备的文件字节无法收回。
