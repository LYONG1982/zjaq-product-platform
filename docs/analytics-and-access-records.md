# 统计和浏览记录

统计属于已确认的附件迭代范围。本地 Mock 与 CloudBase 适配器代码已提供；实际集合、索引、网关、TTL 和真实客户端仍需在获准的目标环境独立验收。

## 开关和权限

- 默认关闭三个独立开关：展示数据看板、销售端下载采集、小程序/H5 浏览采集。
- 仅 `ADMIN` 读取或更新统计设置，更新带版本冲突检查并写操作审计；销售和内容管理员无统计明细或设置权限。
- 看板关闭时管理员 UI 隐藏数值并提示前往系统设置，统计汇总接口返回 403。采集开关独立，不因隐藏看板而隐式停止或开启采集。
- 访客只能读取采集告知与采集开关，不能读取原始 IP、汇总、配置版本或个人信息。
- 关闭采集后服务端重新检查设置；已有记录继续执行原到期规则。客户端缓存了“开启”也不能继续写记录。

## 统计口径

- 浏览：小程序/H5 在成功呈现 PDF/图片或视频开始播放后提交一次。同一查看器实例的翻页、缩放与重试复用 `viewId`，服务端按资料版本、IP、`viewId` 去重。版本或当前公开权限不匹配时拒绝写入。
- 客户端端类型只允许 `H5` / `WECHAT`，属于客户端声明，不能作为真实设备认证。无登录访客统计属于使用次数，不是去重人数，也不能证明用户已完整阅读。
- 下载：仅可信销售身份、当前版本、授权原件下载的完整 HTTP 200 成功响应计数。HTTP 206 Range、预览与中断不计下载，不把视频分段请求计为多次下载。图片序列的完整 ZIP 响应计一次。服务端响应完成不能证明接收方已保存文件。
- 管理端保留资料、版本、时间（界面用北京时间）、事件类型、使用端、服务端观测的 IP，以及已核实销售身份的下载人。分享人没有可核实的服务端分享关联时一律为 `null` / “未记录”；请求 Schema 不接受用户传入分享人或下载人。
- 采集按来源 IP 每分钟最多 60 个新事件，同时受 API 总限流。去重键由服务端散列，不存公开身份令牌，不通过 URL 或反馈字段猜测分享人。

## IP 和反向代理

未配置 `TRUSTED_PROXY_ADDRESSES` 时完全忽略 `X-Forwarded-For`，使用 socket 对端 IP。配置只接受精确 IP 地址，不接受 `*` 或任意网段；从右往左走可信链，停在第一个未列为可信的地址。格式不合法的链退回 socket 对端。

Next.js 销售 PC 以同源会话代理访问 API，服务端默认观测到的是该代理 IP。应用不能在没有可信入站链证明时把浏览器自行设置的转发头当成真实客户端 IP。正式网关需要明确代理地址、覆盖不可信入站头，并实测 IPv4/IPv6、绕过代理和伪造转发头；源码配置不等于这些操作已经验收。

## 保留与恢复

每条原始记录的 `expiresAt` 为创建时间加 90 天，读取时排除已满 90 天的记录。Mock 在写入/读取时删除到期记录；正式 API 源码在启动、每小时以及采集/管理读取时执行物理清理，清理只接受 `analytics` / `rates` 集合。实例停机期间由平台 TTL/运维保留规则补足物理清理，不能用“读取时隐藏”代替停机清理保障。

正式目标应创建 `analytics.expiresAt` 的 TTL 索引，并确认 SDK 日期字段和删除行为；本次未连接真实云。备份不导出已到期原始记录，恢复将合法日期重新转为 `Date`，保持原到期时间且跳过已到期记录，不能重新开始 90 天计时。更早的 format 1 备份缺少 `analytics` 集合时补为空集合，原备份对象保持不变。

备份含 IP 属于私有运维文件，需与线上保留规则一致进行到期销毁，不纳入 GitHub；截图和报告只使用本地虚构数据。匿名日志失败只写事件类型，不把资料名、IP、请求正文或身份凭据写应用错误日志。

## 本地证据

`tests/unit/analytics.test.ts` 覆盖管理员权限、独立开关、严格日期、当前版本/分类拒绝、重复浏览去重、销售完整响应与 Range 排除、关闭生效、IP 防伪造、CloudBase 事务替身并发去重、90 天逻辑/物理删除和备份恢复不过期续命。

`tests/browser/analytics.spec.ts` 覆盖后台开关、H5 真实预览与翻页、看板、浏览记录和关闭状态。浏览器测试结果由本轮最终验证报告单独记录。源码实现、Mock、内存事务替身、真实云、微信设备是不同证据层级。
