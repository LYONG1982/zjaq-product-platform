### 3.2 页面文字删减清单

| 当前或 V3 中的文字类型 | 处理 |
| --- | --- |
| 每页重复的大段“本地模拟、目录、接口、发布说明” | 合并为导航区域一个清晰的“本地演示”标记，详细说明放帮助／操作文档 |
| 装饰性英文标题、拼音标识和中英文重复小标题 | 删除默认展示，保留必要品牌名与文件格式 |
| 同屏重复的页面名、面包屑、内容区标题 | 保留帮助定位的一层标题；首页不叠加多层重复标题 |
| 每个模板字段都重复的长帮助文案 | 普通字段只留名称和必要提示，复杂字段按需展开；不删除发布必填规则 |
| 全部状态统一显示的成功提示或长流程说明 | 改为就近、短句、与当前动作有关的反馈 |
| 无数据的可选模块、空参数标题、装饰统计 | 不展示；不补零、不造统计 |
| 开发术语、JSON 对比、路径错误 | 普通界面用字段名称和清晰差异摘要；技术详情折叠保留用于排错 |

### 可审阅文案草案

- 一句话定位：**从资料中找答案，让出处清晰可查。**
- 简介：将分散的业务文档整理为可检索的资料集合，通过自然语言查找相关内容，并按来源查看原文。适合展示内部知识查询、新人学习和资料更新后的内容核对流程。
- 适用对象：知识维护人员、培训人员和业务支持人员。
- 问题与价值：资料分散 → 集中检索；答案缺少依据 → 同步查看来源；内容更新后难核对 → 按当前资料版本确认。
- 核心能力：按问题查找相关内容、关联来源片段、汇总多个资料要点、由人工确认后使用。
- 场景：新人查阅制度说明；业务人员整理答复依据；资料维护人员检查更新后的引用。
- 输入说明：已整理的示例文档与用户问题；本演示不接收真实敏感资料。
- 输出说明：答案草稿、来源片段和资料名称。答案不代替原文。
- 人工复核与限制：答案可能存在遗漏或理解偏差；涉及重要决定时由使用者核对原文。本产品为虚构展示样例，不表示本平台已经提供 AI 问答服务。
- 部署／评测参数：没有已核实的条件和结果，留空并在阅读端隐藏。

制作配套的中文 PDF 介绍和一套有序图片，用于检查实际字体、长文本、页序与查看器；每份单独打开可见 Demo 标识。不使用真实客户、认证编号、性能数值或价格承诺。不新增 AI 模型调用、聊天入口或付费服务。

脚本保持手动执行、回环 Mock 限制、幂等和用户修改保护；不升级到自动启动灌入，不重置当前会话。若服务代码更新需要重启，先将当前本地会话草稿、发布状态和文件做可复核的本地检查点，再迁移／恢复；确认不能无损恢复时保留旧进程并启用新端口，不直接清空用户会话。检查点只为本地连续开发，不等同 CloudBase 持久化验收。
