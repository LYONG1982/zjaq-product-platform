### 上传与保存规则

1. 点击选择图片后立即本地校验并预览，状态显示“已选择，尚未保存”。读取中禁用保存，避免旧图片先提交；连续替换时只展示最后一次选择结果。
2. 沿用 PNG/JPG、≤240 KiB 的规则；推荐上传清晰原图，保留完整二维码和四周留白。提示真实大小限制，不强制裁剪为正方形，不拉伸、重绘或添加 Logo/水印，不自动进行有损压缩。
3. 图片卡片分别显示错误。格式不支持、超限或读取失败时保留原图与其他已编辑字段，不清空表单。
4. 点击“移除”只标记本次表单待移除，可撤销；保存成功后才影响前台。保存按钮附近明确说明“保存后，前台将不再显示已移除的二维码”。
5. 保存成功提示“已保存，H5 新打开或刷新页面后显示最新内容”；无需重新发布产品或重新构建 H5。已打开页面不承诺无刷新实时同步。
6. 保存失败保留选图与输入；版本冲突说明已被其他管理员修改，允许重新读取，不自动覆盖他人内容。初次读取失败时禁用保存并显示“重新加载”，避免以空表单覆盖已有配置。
7. 表单有变更时，切换后台模块/退出或关闭页面采用现有可用的离开保护方式提示未保存；正常无修改不增加确认。撤销本次修改恢复最近一次成功读取/保存的配置。
8. 保持 ADMIN 修改权限及现有审计，不增加非管理员配置权限。

## 二、H5 底部展示

继续使用“与我们联系”标题及既有电话入口，首页和产品详情共享同一份后台配置，不为各产品重复上传。

| 配置或运行状态 | H5 表现 |
| --- | --- |
| 两张二维码已配置 | 两列等宽并排；上方完整图片、下方“官方公众号”/“客服微信” |
| 仅配置一张 | 单张居中，保留适当最大宽度，不拉伸占满整行 |
| 两张均未配置 | 收起二维码行，保留已配置电话，不向访客显示两个“暂未配置”空框 |
| 电话与两张图片均为空 | 收起整个联系区域，不留下空白卡片 |
| 图片加载失败 | 保留对应用途名称，显示“二维码加载失败，点击重试”，不误报成未配置 |
| 配置接口首次加载失败 | 紧凑提示“联系方式暂时无法加载”及重试，不显示假二维码 |
| 已有内容后的刷新失败 | 保留最后一次成功读取内容并提供重试，不能用失败结果清空已有内容 |

视觉与交互：

- 白色联系卡片，二维码图片放在白色方形展示区内，完整等比例展示，保留原图留白；装饰色只用于图片外部容器。
- 二维码展示区域最大约 128px，受可用列宽约束时等比例缩小；两列间距约 12px，不用固定尺寸造成 320px 窄屏溢出。标题约 18px、二维码用途约 14px、辅助提示约 12px，沿用既有字号体系。
- 点击二维码打开大图，可关闭返回原滚动位置；H5 保留可查看的图片。默认提示“点击查看大图”，微信长按识别/保存属于客户端能力，未经真机验证不承诺自动识别、自动关注或自动添加好友。
- 适配 320/390/430px 宽度与底部导航、安全区，二维码和关闭按钮均不被遮挡。
