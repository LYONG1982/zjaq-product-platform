## 3. 本轮交付目标

在同一套本地工程中完成：**新增 → 按模板制作 → 保存 → 草稿预览 → 模拟发布 → 修改草稿 → 发布更新 → 下架／重新发布**。同一个模拟内容管理员可完成全过程。

本轮继续采用回环地址的统一 Mock API。页面标明本地模拟环境，“发布”仅使内容出现在这套本地公开目录中。业务状态在 Mock 进程内管理，上传字节暂存在 work 下的私有目录；不使用 localStorage 保存业务库，不宣称跨实例事务或云端持久化。重启会清空本轮模拟业务状态；可重新执行独立验证数据脚本恢复演示数据。

完成时应能使用网页界面新增一款非首批产品、上传测试预览件、发布并在 PC/H5 列表搜索到。完整阅读端详情、全屏／缩放／翻页等跨端查看器体验仍由后续 TASK-04／05 完成，本轮不把基本列表当作阅读端全部交付。

## 4. 后台交互

### 4.1 产品管理与新增向导（A01／A02）

- 在现有表格加入“新增产品”和编辑入口，保留搜索、分页、分类／状态筛选，增加修改提示、更新时间与清晰的危险操作区域。
- 两步向导：分类与模板 → 基础信息。分类、默认模板和允许模板由接口决定；切换分类时保留兼容模板，不兼容则明确提示切换默认值。
- 填名称、负责人和可选别名；编号由服务器计数器产生。重复名称仅提醒，允许明确继续，不把名字当唯一键。
- 创建期间禁用连点；网络重试复用原 Idempotency-Key。取消未提交向导不生成空产品。

### 4.2 内容编辑与保存（A03）

- 按现有七模块和四模板动态渲染字段：基本信息、问题与价值、功能、场景、参数与边界、素材、资料。
- 模板 ID／版本创建后固定；分类修改必须兼容当前模板。旧模板禁用新建后，已有草稿仍按原版本读取。
- 首期只做手动保存，避免引入尚未处理完善的自动保存。PATCH content 为完整草稿替换，带 expectedDraftVersion；缺少发布必填可以存为草稿。
- 冲突返回 409，保留本地输入并提供重新读取／对比；不自动覆盖别人的版本。离开时提供保存并离开、放弃修改、继续编辑；失败不显示保存成功。
- 预览、发布先保存当前输入；保存失败停留编辑器。下架独立于草稿保存，不被未保存或不完整输入阻塞。

### 4.3 资料、素材与草稿预览（A05／A04）

- 产品内资料抽屉维护名称、用途、版本标签、适用版本、PDF／有序图片预览件、可选 PPTX／DOCX 源件；图片显式排序，材料／版本 ID 稳定且校验唯一性。
- 替换形成新 assetId 和 versionId；同 materialId 不复用既有版本标签。移除只改变草稿，直到再次发布，不删除旧快照所需字节。
- 上传界面展示上传中／检查中／可用／失败，支持重试。没有自动 Office 转 PDF，不伪造转换进度。
- 独立草稿预览视图支持 PC／移动宽度切换和返回编辑，始终标注未发布。读取指定 draftVersion，过期返回 409；不产生审批状态或“看完才能发布”的凭证。
- 后台资源通过带开发令牌的请求读取；令牌不放 URL，获取 blob 后及时释放。匿名资源请求拒绝访问；模拟身份限制在页面和报告中说明，不能当作真实登录验证。

### 4.4 发布、更新、下架与操作记录

- 简短发布确认显示产品名、资料数量、替换提示和可公开声明。服务器校验通用／模板必填、至少一份可用预览、归属、版本与声明。
- 使用 draftVersion 与 publicationVersion 双检查；创建不可变 release 后原子切换当前指针，同步记一次操作结果。失败不出现半套正文或资料。
- 修改已发布草稿不改变公共结果；再次发布整体替换。下架清空 activeReleaseId、递增 publicationVersion，保留草稿／历史；从未发布不能直接转为 OFFLINE。
- 幂等按操作者＋规范化操作路径＋Key＋规范化请求哈希计算。重复操作返回原结果；同 Key 不同内容返回 409；失败注入仅从测试内调用，不开放调试 HTTP 入口。
- 增加轻量操作记录页／产品操作记录视图和既有 audit-events 读取接口，显示操作、产品、版本、时间和模拟操作者，不构建审批时间线。

## 5. Mock API、文件与公共读取

### 5.1 实现范围

在已有 9 项读取接口基础上，计划实现 14 项既有契约操作，合计 23／28 项：

| 组 | 本轮新增操作 |
| --- | --- |
| 草稿和发布 | createProduct、saveProductDraft、previewProductDraft、publishProduct、unpublishProduct |
| 上传和后台文件 | createUpload、putUploadBytes、completeUpload、getUpload、streamDraftAsset |
| 操作记录 | listAuditEvents |
| 当前公开资源 | getCurrentPreview、streamCurrentPreview、streamCurrentMedia |

保留未实现的 5 项分类／账号写管理接口为明确不可用：createCategory、updateCategory、listAdminUsers、createAdminUser、updateAdminUser。本轮已有四分类足以验证模板制作；自定义分类管理及真实后台账号管理另行安排。

### 5.2 文件校验与资源隔离

- 模拟存储仍接收实际测试字节：先创建上传任务，再 PUT 字节，最后 complete；不能让客户端自报 READY、hash 或 pageCount。上传目标由服务端生成，不能传入任意本地路径或远程 URL。
- 沿用原包上限：PDF 30 MiB、图片 8 MiB、Office 源件 50 MiB、单材料 200 图片页、单产品 20 资料；增加请求正文、会话总量和解析超时限制，避免本地演示服务无限占用资源。
- 校验声明大小、实际大小、类型签名、可解析结构、页数／完整性和归属；图片解码后去除不必要元数据；PDF 不执行脚本；Office 源件只校验受限容器结构，不执行宏、不转换。不声称完成恶意代码扫描。
- 必要的 PDF／图片／ZIP 解析及后台显示依赖在确认后查阅官方资料，固定兼容版本、审计并验证。解析采用超时和尺寸／资源限制；损坏或不支持格式明确 REJECTED，不通过简单后缀猜测宣称安全。
- work 下的临时文件目录不作为静态目录暴露；已 READY 资产不可覆盖，跨产品引用被拒绝。后台源件不进入 Public DTO 或预览 manifest。
- 当前公开资源每次核对 activeReleaseId、materialId、versionId；更新后旧版本返回 409，下架／移除／不存在返回 404。保持 no-store，实施单段 Range 的 200／206／416 和准确响应头；不生成永久对象直链。

### 5.3 基本公开列表配套

- 公共分类、产品、资料与详情 API 从当前 release 白名单投影；过滤后再分页，排序使用发布时间及编号；搜索仅名称／别名和契约规定的资料名称，本轮不扩张为全文搜索。
- PC 和 Uni-App 显示真实返回的产品／资料行、明确的验证数据标题及“已加载”数量；支持加载更多，避免只显示 count 或遗漏第二页。
- 页面重新显示或用户刷新时重新取数，避免下架后继续发起新的旧资源请求。保留空态、错误态与请求序号保护。
- 不加入尚未实现的“查看详情／预览”死链接；完整公开详情／查看器在后续轮次实现。后台草稿预览与 API 的当前版本资源检查本轮可独立验收。
