# 本轮代码审核与修复结果

日期：2026-10-29。范围：附件主计划及安全移除补充计划的源码。**已修复本轮发现的功能、访问边界及文件链路阻塞问题；最新本地检查、77 项单元/API、3 项迁移预检、56 项 Playwright、四目标构建通过。** 真实云/微信/部署未验收；依赖基线告警单列，不宣称漏洞清零。

## 独立复核与确定问题

| 问题 | 修复和验证 |
| --- | --- |
| PC 旧目录和旧资源代理可匿名访问 | 所有 PC 入口和兼容代理要求可信销售会话，服务端页面和资源重验身份；匿名/跨站/退出/失败登录 API 及浏览器通过。 |
| 大文件上传旧配额、Buffer 和短超时 | 统一 500 MiB、File/XHR、磁盘流、受控并发/配额/空闲及总时限；PDF 范围解析、Office 条目流；真实 499/500 MiB、500 MiB MP4 和浏览器 File 通过，501 MiB 拒绝。 |
| 云 SDK 下载未等写盘完成 | 核对安装版本源码，改官方元数据授权 + 受限 HTTPS pipeline，等待文件完成并校验长度和 SHA-256，不外发私有 URL。真实云仍待验。 |
| 视频 Range 反复下载整件对象 | 有界 2 GiB 私有磁盘缓存、并发去重、引用保护和 2 分钟空闲清理；权限仍按每个新请求检查，缓存首填完整校验；去重/过期测试通过。 |
| 后台视频令牌、过期和长播放 | 独立 AES-GCM、5 分钟服务端到期、HttpOnly/Strict/生产 Secure、只读路径、每 Range 身份校验及续期；篡改/过期/禁用测试和实际原生视频通过。 |
| 原图被覆盖、图集源件无完整下载 | 原件与安全派生图分开，原始校验和及扩展名保持，销售逐页 ZIP64 流；外部 unzip 校验及原件/派生隔离通过。 |
| 拒绝文件残留已删除对象引用、租约及断流清理 | persisted 剥离存储内部字段，REJECTED 不保留失效 fileId，失败回收对象、半文件和租约；40 分钟 fenced 租约覆盖分阶段时限，响应中断/超时释放引用。 |
| UUID 索引掩盖重复主档 | 独立校验所有主档 UUID 唯一性，索引存在也不能绕过；旧编码直达拒绝，重复/错配/备份校验通过。 |

| 资料分类收紧后旧公开资源仍可访问 | 明确宣传分类且当前草稿仍允许才对外；收紧后新列表、直达与 Range 被拒绝，放开需重新发布；Mock/事务替身通过。已经传输的字节无法收回。 |
| 历史版本建议重复、历史无法查阅 | 版本列表/预览、读取历史后跳过已用标签、失败重试和服务端重复/并发检查；管理流程通过，销售只读当前发布。 |
| 统计可伪造 IP/分享人、重复分段计数及超期恢复 | 精确信任代理链、服务端身份、拒客户端分享人、完整下载响应计数、浏览去重、三个独立开关、90 天过滤/清理及恢复原期限；API/事务/浏览器通过。 |

## 依赖和外部证据

`pnpm audit --prod --json` 记录 35 条告警（7 高、20 中、8 低、0 严重）。多数来自固定 Uni-App 工具链及未在业务使用的 HTML 翻译/数据库 watch 路径。已增加开发服务器 Host/Origin/跨站及编辑器入口防护，并核对官方修复信息；这些措施不等于依赖升级或所有漏洞消除。未做未批准的主版本升级，完整清单与剩余风险见 [依赖安全审核](2026-10-29-dependency-security-review.md)。

本轮未发现仍未修复的已确认功能阻塞；真实 CloudBase SDK/IAM/事务容量、网关、TTL、实际代理链、微信设备和真实内容需在单独授权目标验收。开发服务器不可当公网生产服务器。源码推送不改变这些边界。
