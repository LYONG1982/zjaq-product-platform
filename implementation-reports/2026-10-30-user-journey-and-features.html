四条核心用户旅程

每条旅程同时说明操作、反馈和失败边界，避免只把页面数量当作功能闭环。

01

管理员 / 内容管理员：从建档到发布

目标：把产品信息和可用资料可靠地整理成一个可发布版本。

  1. 进入工作台身份识别后展示角色菜单；按关键词、系列、状态、资料负责人筛选。
  2. 创建产品选择系列和模板，填写名称、负责人、型号、产品类型及属性；提交时由系统分配编码。
  3. 补齐产品内容填写摘要、价值、能力、场景、参数等章节；已有产品支持继续编辑。
  4. 上传与整理资料先选文件 → 点击上传 → 真实进度 → 服务端检查 → 填资料信息 → 完成。
  5. 保存 / 预览 / 发布“完成”只加入当前编辑；保存草稿后，发布才更新阅读端。预览、发布会先保存。
  6. 持续维护编辑产生后续资料版本；可下架；管理员可安全移除并按需恢复，恢复不自动上架。
异常与边界 重名可选择独立建档；离开有未保存提示；并发冲突保留比较与处理入口；发布校验不通过时需修正。移除保留编码、型号、UUID、文件、历史和审计。

02

上传资料：文件优先的微旅程

目标：先确认文件可用，再填写资料信息，清楚知道何时已上传、何时已保存、何时已发布。

  1. 选择文件只做本地格式 / 500 MiB / 数量检查并排队，不发送文件内容。
  2. 点击上传显示 3px 横线及真实字节进度；传输中防重复提交与关闭。
  3. 等待检查100% 字节传完后仍需服务端检查；READY 才提示“上传成功”。
  4. 填写信息名称默认文件名（去扩展名），手改名保留；新版本默认 V01.0，可编辑；分类必须匹配。
  5. 完成并保存文件、名称、版本、分类均有效且无待传 / 失败时，“完成”才可点；随后保存草稿、发布更新。
异常与边界 删除只解除本次选择 / 关联，可继续上传。多文件部分失败时保留旧预览和成功暂存件；重试复用成功部分。整批成功自动采用；删除失败项后仍有暂存件时，须显式“应用已上传文件”。PPTX / DOCX 仅源件，需另配 PDF、图片或视频预览；适用型号 / 版本可选。

03

销售 PC：检索 → 了解 → 演示 / 下载

目标：登录后快速找到准确产品、型号和最新资料，服务销售沟通。

  1. 登录与返回未登录访问业务页转销售登录，保留允许的返回地址；本地模拟仅限开发开关。
  2. 筛选目录产品名 / 别名、系列、属性和更新时间筛选；游标加载更多。
  3. 阅读产品详情用公开 UUID 进入详情，查看型号、章节及资料；返回保留检索状态。
  4. 打开当前资料PDF 页码 / 缩放 / 键盘 / 全屏，图集按页查看，视频播放与兼容提示。
  5. 下载资料绑定当前发布和资料版本；优先原始源件，无源件的图集打包 ZIP，其余下载预览文件。
异常与边界 会话约 30 分钟；过期重新登录。内容下架或版本改变会阻止继续使用旧链接，并提示打开当前版本。真实 CloudBase 登录、线上存储与下载未在本轮验证。

04

H5 / 小程序：发现产品 → 阅读宣传资料 → 联系 / 反馈

目标：访客无需销售账号也能了解对外产品内容，并找到联系入口。

  1. 首页进入可配置 Banner 位、搜索、四系列入口和推荐产品；H5 当前已取消顶部 LOGO，保留本地演示状态。
  2. 搜索与浏览首页 / 产品 / 资料三 Tab；系列筛选、关键词与加载更多；专属封面优先，缺失回退系列图标。
  3. 阅读产品四系列主题、清晰内容卡、锚点与能力弹窗；长标题换行、关键热区至少 44px。
  4. 预览宣传资料PDF、图集、视频；仅当前发布、发布快照与最新草稿均明确归为宣传资料，且未撤销的版本可公开。
  5. 联系与反馈联系方式、公众号 / 客服二维码配置；暂无正式图片时占位。首页提供反馈，成功后清空表单。
异常与边界 公开 UUID 只是标识，权限由发布状态、分类和版本校验决定。H5 / 小程序无源件下载按钮；浏览器获取预览字节不等于无法保存预览。小程序 PDF 使用 openDocument；真机打开、视频兼容、微信审核类目与送审仍须独立验证。

如何做一轮人工 UAT
  1. 内容管理员创建草稿，选择 PDF 后确认未自动上传；上传、删除、重传并完善资料。
  2. 确认“完成”仅回到编辑器，再保存并发布，观察阅读端更新。
  3. 销售用本地验证身份完成搜索、预览、下载；更新资料后检查旧链接失效。
  4. H5 访问同产品，只能预览宣传资料，技术资料与源件不公开；检查返回、搜索及联系入口。
  5. 管理员检查记录和统计开关，内容管理员确认看不到管理员专用浏览记录 / 配置。

不得把以上人工建议写成已经执行的验收结果；真实环境步骤需部署工程师在对应环境另外完成。
