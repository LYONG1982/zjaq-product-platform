# 统计与浏览记录本地验证（2026-10-29）

本报告只记录本轮新增统计模块的实际本地证据，不能代替全量回归或真实 CloudBase / 微信设备验收。正式汇总以最终本轮发布验证报告为准。

| 项目 | 实施与证据 |
|---|---|
| 统计设置 | 管理员独享，展示看板 / 下载采集 / 浏览采集三个独立开关，默认关闭，版本冲突检查和操作审计 |
| 看板关闭 | UI 隐藏数值并引导去设置；汇总接口 403，采集独立受控 |
| 浏览 | H5 PDF / 图片成功显示、微信图片加载 / 原生 PDF 成功打开或视频开始播放后提交；同一次打开的翻页不加次数，服务端去重与版本/公开分类校验 |
| 销售下载 | 可信销售完整 HTTP 200 响应完成记一次，预览、Range 206、中断不计下载；图片序列 ZIP 完整响应记一次 |
| 浏览记录 | 操作记录下新增“浏览记录”标签，支持资料/产品名、事件、使用端和北京时间日期筛选，含资料版本、时间、端、来源 IP、核实的下载人、未记录的分享人 |
| 分享人 | 请求不接受客户端指定分享人或下载人；没有可信分享关联时 `null` / “未记录” |
| IP | 默认只取 socket，对伪造 XFF 不信任；精确配置可信代理后从右往左解析，格式错误回退；销售 Next 代理的观测 IP 限制已说明 |
| 限流 | 每来源 IP 每分钟 60 个新事件，重复同一次浏览不重复入库，另受 API 总限流 |
| 保留 | 读取排除 90 天以上记录；Mock 写/读删除到期项，正式适配器支持按日期物理删除，API 启动/每小时和读取/采集触发清理；真实 TTL 需目标环境核验 |
| 备份恢复 | 老 format 1 缺少 analytics 时补空；校验事件 Schema 和固定到期时间，备份不导出过期原始 IP，恢复转回 Date 并保留原到期时间，过期项跳过 |
| 容量 | 统计使用独立 `_id` 游标扫描，绕开通用 10,000 条导出上限；本地事务替身验证 10,002 条读取 |

实际命令与结果：

1. `node --import tsx --test tests/unit/analytics.test.ts`：**4 / 4 通过**。覆盖 API 权限、开关、严格日期、伪造字段、当前分类/版本、去重、Range 排除、完整下载、关停、60 次限流、可信 IP、Cloud 事务替身并发、持久化重建、到期清理、恢复日期和 10,001 条增量容量。
2. `pnpm check`：**通过**，含生成文件一致、服务端/PC/管理端/H5 TypeScript 检查。
3. `VITE_API_BASE_URL=http://127.0.0.1:3303/api/v1 pnpm build:h5`：**通过**，使用本轮最新手机详情和视频/统计代码。
4. `CHROMIUM_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' pnpm test:browser tests/browser/analytics.spec.ts`：**1 / 1 通过**。覆盖后台三开关、H5 PDF 实际渲染、翻页去重、看板计数、记录内容和关闭后的告知/采集/看板行为。初次失败为 Uni-App `uni-button` 选择器类型与原生 button 不同；改用项目既有 H5 选择器后通过。
5. `node --import tsx --test tests/unit/analytics.test.ts tests/unit/cloud-adapter.test.ts` 当时为 **11 / 12**；唯一失败是并行 Banner 新增字段后的旧响应形状断言，已交由根代理更新。此结果不称为全量通过。
